# Majora's Mask 3D — Tradução PT-BR

Projeto experimental de tradução para português brasileiro de **The Legend of Zelda: Majora's Mask 3D**, destinado ao port nativo **Moonfall Curse (TriAevum)**.

A tradução está em fase inicial de desenvolvimento. Alguns diálogos já foram testados em português, mas a maior parte do jogo ainda permanece no idioma original.

**Não há versão completa nem lançamento estável disponível.** O conteúdo deste repositório é experimental e pode mudar.

## Créditos

- Tradução PT-BR: [XandasL](https://github.com/XandasL)
- Port nativo: [TriAevum / Moonfall Curse](https://github.com/coccofresco/TriAevum)

*The Legend of Zelda* e *Majora's Mask 3D* pertencem aos respectivos titulares. Este projeto não distribui o jogo ou arquivos originais da ROM. Os componentes derivados do TriAevum seguem as licenças aplicáveis do projeto original.
